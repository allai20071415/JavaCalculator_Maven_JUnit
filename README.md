# Java Calculator - Maven + JUnit 5

## Project
A Java Calculator application with a `subtract()` function and a JUnit 5 parameterized test containing 6 test cases.

## Requirements
- JDK 17 or later
- Maven
- VS Code with Extension Pack for Java

## Run
Open the project folder in VS Code, open Terminal, and run:

mvn clean
mvn compile
mvn test

Expected result:
Tests run: 6, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
